# 🌌 Kainatın En Gereksiz Bahane Üreticisi

> **"Tembellik bir tercih değil, bir bilimdir."**  
> — Bilinmeyen bir filozof (muhtemelen bu projenin yazarı)

## Bu Nedir?

Bu repository, insanlığın en büyük problemlerinden birine çözüm sunar:  
**"Bugün neden hiçbir şey yapmadım?"** sorusuna abartılı, dramatik ve bilimsel görünümlü cevaplar üretmek.

Diğer yazılımlar size üretken olmayı öğretir.  
Bu yazılım size **üretken olmamayı** meşrulaştırır.  
Ve bunu **büyük bir ciddiyetle** yapar.

## Özellikler

- 🎯 **15 adet bilimsel temelli bahane** (hepsi uydurma)
- ⏳ Dramatik yükleme animasyonu (gerçekçi hissettirmek için)
- 🧠 Kuantum fiziği, felsefe, kedi telepatisi ve ejderha rüyaları desteği
- 📜 Kullanım hakkı: Sonsuza kadar, herkese, her yerde
- 🔒 Gizli mesajlar içerir (ama bulamazsınız, çünkü gizli)

## Kurulum

```bash
git clone https://github.com/Tentivory/kainatin-en-gereksiz-bahane-ureticisi.git
cd kainatin-en-gereksiz-bahane-ureticisi
python bahane_ureticisi.py
```

Başka bir şey gerekmez. Python 3 varsa yeter. Hatta yoksa da bahane üretmeye devam edebilirsiniz (zihninizde).

## Kullanım

Sadece çalıştırın. Program sizin için bir bahane seçecek.  
Sonra o bahaneyi ailenize, arkadaşlarınıza, patronunuza veya aynadaki yansımaya söyleyin.

Örnek çıktı:

```
🎯 BUGÜNKÜ RESMİ BAHANEN:
--------------------------------------------------
"Rüyamda bir ejderha bana 'bugün hiçbir şey yapma' diye fısıldadı. Ejderhalara karşı gelinmez."
--------------------------------------------------
```

Çünkü bazen hiçbir şey yapmamak da bir başarıdır.
